🔑 Une clé pour la 3D

La 3D vient de Google, distribuée par Cesium. Il faut une clé gratuite, à faire une seule fois :

  1. Crée un compte gratuit sur ion.cesium.com (compte « Community »).
  2. Dans Asset Depot, cherche Google Photorealistic 3D Tiles et clique Add to my assets.
  3. Dans Access Tokens, copie le Default token et colle-le ici.

La clé reste dans ce navigateur, sur cet ordinateur. Elle n'est envoyée qu'à Cesium.
